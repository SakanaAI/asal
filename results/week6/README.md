# Verified comparison data

The ten CSV files are copies of the week 6 comparison logs. The ten configuration JSON files are direct copies of each run's root `meta.json`. Consult `run_manifest.json` for original run IDs and file mappings.

`energy_summary.json` derives endpoint means and sample standard deviations from these logs. Full cell distributions live in the original checkpoints, which should remain in local `data/raw/`.

Entropy has not been calculated by this starter pack. Read `docs/DATA_NOTES.md` before interpreting the comparison or genome counts.
